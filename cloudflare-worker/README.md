# ตัวกลาง Cloudflare Worker (ไม่บังคับ แต่ช่วยให้เร็วขึ้นเมื่อเครือข่ายไปหา Google ช้า)

เบราว์เซอร์เรียก Cloudflare แล้ว Cloudflare เรียก Google Apps Script แทน (เหมือนที่โปรเจกต์ตัวอย่างใช้เซิร์ฟเวอร์ของตัวเองเป็นตัวกลาง)
แผนฟรีให้ 100,000 คำขอต่อวัน ซึ่งเกินพอ ถ้าตัวกลางล่ม แอปจะกลับไปเรียกสคริปต์ตรงเองอัตโนมัติ

## ติดตั้ง (ทำครั้งเดียว ประมาณ 5 นาที)

1. ล็อกอิน https://dash.cloudflare.com แล้วเมนูซ้าย **Workers & Pages** (หรือ "Compute (Workers)")
2. กด **Create** → **Create Worker** (เลือก "Start with Hello World!" ถ้ามีให้เลือก)
3. ตั้งชื่อ เช่น `opr-list-relay` แล้วกด **Deploy** (จะ deploy โค้ดตัวอย่างไปก่อน ไม่เป็นไร)
4. กด **Edit code** → ลบโค้ดเดิมทั้งหมด → วางโค้ดจากไฟล์ [`worker.js`](worker.js) ทั้งไฟล์ → กด **Deploy** (มุมขวาบน)
5. คัดลอก URL ของ Worker (หน้าตา `https://opr-list-relay.ชื่อบัญชี.workers.dev`)
6. ทดสอบ: เปิด `URL?action=ping` ในเบราว์เซอร์ ต้องเห็น `{"status":"success","message":"เชื่อมต่อสำเร็จ"}`
7. ส่ง URL ให้ผู้พัฒนาใส่ในแอป (ค่า `DEFAULT_PROXY_URL` ใน `src/services/sheetApi.ts`)

## ถ้าเปลี่ยน URL ของ Apps Script
แก้บรรทัด `DEFAULT_APPS_SCRIPT_URL` ใน Worker (Edit code) แล้ว Deploy ใหม่ หรือตั้งตัวแปร `APPS_SCRIPT_URL` ในแท็บ Settings → Variables

## ถ้าเปลี่ยนที่อยู่เว็บ
เว็บที่ใช้ตัวกลางได้ถูกจำกัดไว้ที่ `https://ratthammanoon221042-lang.github.io` (และ localhost สำหรับทดสอบ) ถ้าย้ายเว็บไปที่อื่น
ให้ตั้งตัวแปร `ALLOWED_ORIGINS` (คั่นด้วยจุลภาค) หรือแก้รายการ `DEFAULT_ALLOWED_ORIGINS` ในไฟล์

## ความปลอดภัย
- เรียกได้เฉพาะสคริปต์ของเราเท่านั้น ผู้เรียกกำหนดปลายทางเองไม่ได้ และส่งต่อเฉพาะ action ที่แอปใช้
- ไม่เก็บและไม่แคชข้อมูลหรือรหัสผ่านที่ผ่านมา การล็อกอินและสิทธิ์เพิ่ม/แก้/ลบยังตรวจที่ Apps Script เหมือนเดิม
- จำกัดเว็บที่เรียกผ่านเบราว์เซอร์ได้ด้วย ALLOWED_ORIGINS (ป้องกันเว็บอื่นมาใช้โควตา) แต่คนที่ไม่ใช้เบราว์เซอร์ยังเรียกได้
  ซึ่งก็เข้าถึงได้เท่ากับเรียก URL ของสคริปต์ตรง ๆ อยู่แล้ว

## ปุ่ม "กรอกจากรูป" (อ่านรถยนต์จากภาพ/ไฟล์หนังสือ) ตั้งค่าครั้งเดียว

ปุ่มนี้ให้ AI ของ Google (Gemini) อ่านภาพหรือ PDF แล้วกรอกรายการรถยนต์ให้ในตาราง (ข้ามรถจักรยานยนต์) คนกรอกต้องตรวจก่อนกดบันทึกเสมอ
ตัวฟรีของ Google มีโควตาจำกัดต่อนาทีและต่อวัน และ **ข้อมูลที่ส่งอาจถูก Google นำไปปรับปรุงผลิตภัณฑ์** (เงื่อนไขของแพ็กเกจฟรี) อย่าใช้กับเอกสารลับ

1. สร้างคีย์ที่ https://aistudio.google.com/apikey (ล็อกอินด้วยบัญชี Google) กด Create API key แล้วคัดลอกไว้ **อย่าส่งคีย์ในแชตหรือใส่ในโค้ด**
2. ที่หน้า Cloudflare ของ Worker: **Settings → Variables and Secrets → Add** เลือก Type = **Secret** ชื่อ `GEMINI_API_KEY` ค่า = คีย์ที่คัดลอก แล้วกด Deploy
3. (ไม่บังคับ) เพิ่มตัวแปรธรรมดาชื่อ `GEMINI_MODEL` เพื่อเลือกรุ่น (ค่าเริ่มต้น `gemini-flash-latest`) ถ้า Google เปลี่ยนชื่อรุ่นหรือถอดรุ่นนั้นออกจากแพ็กเกจฟรี
4. วางโค้ด `worker.js` ล่าสุดแทนของเดิม แล้ว Deploy
5. วาง `apps-script/Code.gs` ล่าสุดใน Apps Script แล้ว Deploy → Manage deployments → แก้ไข → Version: **New version** (Worker ใช้ action `checkToken` เพื่อให้เฉพาะคนที่ล็อกอินแล้วใช้ปุ่มนี้ได้)

ถ้ายังไม่ได้ตั้งคีย์ ปุ่มจะแจ้งว่ายังใช้ไม่ได้ ส่วนการกรอกเองใช้ได้ตามปกติ

### ถ้าช้าหรือขึ้นว่า AI หนาแน่น (503)
- ค่าเริ่มต้นคือ **ให้โมเดลคิดตามปกติ** (ไม่ส่งคำสั่งเรื่องการคิด) หลังอ่านเสร็จจะแสดง "อ่านเสร็จใน X วินาที" พร้อมรุ่นและแบบการคิด (เอาเมาส์ชี้ดูเวลาแยก) ถ้าอยากให้เร็วขึ้นโดยแลกกับความลึกในการคิด ตั้งตัวแปร `GEMINI_THINKING` = `minimal` หรือ `low` (กำหนดตายตัว) หรือ `auto` (ลองเองแล้วจำ แต่เปลืองคำขอตอนลอง) หรือ `off`
- ถ้า Google ตอบ 503 / โควต้ารุ่นหลักเต็ม จะลองซ้ำและสลับไปรุ่นสำรองให้เอง ตั้งรุ่นสำรองได้ที่ `GEMINI_FALLBACK_MODELS` (คั่นด้วยจุลภาค ค่าเริ่มต้น `gemini-flash-lite-latest`)
- ภาพที่ใหญ่เกินจำเป็นถูกย่อก่อนส่ง (ด้านยาวไม่เกิน 1800 พิกเซล) การส่งไฟล์ PDF ต้นฉบับหรือถ่ายเอกสารตรงๆ ในที่สว่างมักแม่นกว่าภาพแคปหน้าจอที่ย่อมา
