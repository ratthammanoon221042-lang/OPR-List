# รายการขออนุญาตจอดค้างคืน

เว็บแอปบันทึกคำขออนุญาตจอดรถค้างคืน (ชั้น B1 / B2) พร้อมปฏิทินสรุปยอดรายวัน ให้ รปภ. ตรวจสอบรถ และส่งออกรายงานเป็น PDF / Excel / CSV

- ข้อมูลเก็บใน **Google Sheet** ผ่าน Google Apps Script (`apps-script/Code.gs`) ทุกเครื่องเห็นข้อมูลตรงกัน
- ดูรายการได้โดยไม่ต้องล็อกอิน ส่วนการ **เพิ่ม / แก้ไข / ลบ** ต้องใช้รหัสผ่าน ซึ่งตรวจฝั่งเซิร์ฟเวอร์ (Apps Script) และเก็บเป็น hash
- นับคืนจอด **รวมวันสิ้นสุดด้วย** เช่น ขอจอด 6–8 ต.ค. = 6, 7 และ 8 (3 คืน)

## ติดตั้งและรัน

```bash
npm install
npm run dev        # http://localhost:3000
```

คำสั่งอื่น: `npm run build`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run check` (รวมสามอย่างหลัง)

## Google Sheet และรหัสผ่าน

แอปเชื่อมกับ Google Sheet ผ่าน Apps Script ที่ deploy ไว้แล้ว URL อยู่ที่ `DEFAULT_APPS_SCRIPT_URL` ใน [`src/services/sheetApi.ts`](src/services/sheetApi.ts) (ใส่ `VITE_APPS_SCRIPT_URL` ใน `.env.local` เพื่อใช้ URL อื่นแทนได้)

**ติดตั้ง / อัปเดตสคริปต์** (ทำเมื่อสร้างชีตใหม่ หรือเมื่อ `apps-script/Code.gs` เปลี่ยน)
1. เปิด Google Sheet > **ส่วนขยาย > Apps Script** วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) แล้วบันทึก
2. ครั้งแรก: **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป** ตั้ง "ดำเนินการในฐานะ" = ตัวฉันเอง และ "ผู้มีสิทธิ์เข้าถึง" = ทุกคน (ถ้าตั้งเป็นอย่างอื่น แอปจะขึ้น HTTP 404)
   - ครั้งต่อไปที่แก้โค้ด: **จัดการการทำให้ใช้งานได้ > ไอคอนดินสอ > เวอร์ชัน "เวอร์ชันใหม่" > ทำให้ใช้งานได้** URL จะคงเดิม
3. นำ URL ที่ลงท้าย `/exec` ไปใส่ใน `DEFAULT_APPS_SCRIPT_URL` (ถ้า deploy ใหม่แบบ "รายการใหม่" URL จะเปลี่ยน ถ้าแก้ deployment เดิมเป็นเวอร์ชันใหม่ URL จะคงเดิม)

**รหัสผ่าน**
- ล็อกอินครั้งแรกด้วย `1234` แอปจะบังคับให้ตั้งรหัสใหม่ทันที (อย่างน้อย 6 ตัวอักษร)
- เปลี่ยนรหัสได้ด้วยปุ่ม "เปลี่ยนรหัสผ่าน" หลังล็อกอิน รหัสใหม่มีผลทุกเครื่อง
- ล็อกอินผิดเกิน 5 ครั้งจะถูกล็อก 5 นาที
- ลืมรหัสผ่าน: เปิด Apps Script แล้วรันฟังก์ชัน `resetPassword()` จะกลับไปใช้ `1234`

**ความเร็ว:** รายการที่โหลดแล้วถูกจำไว้ในเครื่อง หน้าเว็บจึงขึ้นทันที ส่วน Apps Script ช้ากว่าฐานข้อมูลทั่วไปโดยธรรมชาติ (เริ่มทำงานครั้งแรกอาจใช้ 2–5 วินาที) จึงออกแบบให้ใช้คำขอน้อยที่สุด: บันทึก/แก้/ลบใช้ 1 คำขอ และตอบกลับพร้อมรายการล่าสุด, การอ่านใช้แคช 2 นาทีฝั่งสคริปต์, ล็อกอินใช้ token ที่ตรวจเองได้โดยไม่ต้องอ่านชีตหรือแคช (หมดอายุใน 12 ชั่วโมง) ถ้าแก้ข้อมูลในชีตด้วยมือโดยตรง จะเห็นในแอปภายใน 2 นาที

เพื่อไม่ให้ความช้าของ Apps Script กวนการใช้งาน: รายงานและหน้าจอแสดงข้อมูลที่เครื่องจำไว้ได้ทันที (และพิมพ์/PDF ระบุเวลา "ข้อมูลจาก Google Sheet ณ ...") ถ้า Google ตอบช้าหรือเน็ตหลุดตอนบันทึก แอปจะลองส่งซ้ำเอง 1 ครั้ง (ปลอดภัย ไม่เกิดรายการซ้ำ) และมี workflow `keep-warm.yml` ยิงคำขอเบา ๆ ทุก 10 นาทีในเวลาทำการ (จันทร์–ศุกร์ 07:00–17:59) เพื่อลดอาการช้าครั้งแรก (รันเฉพาะจาก default branch ของ repo)

## โครงสร้าง

| ส่วน | ที่อยู่ |
| --- | --- |
| Backend (Apps Script + ทดสอบ) | `apps-script/` |
| ตัวเรียก backend | `src/services/sheetApi.ts` |
| กฎวันที่ / นับคืน | `src/utils/dateUtils.ts` |
| ปรับข้อมูล / ตรวจทะเบียนซ้ำ | `src/utils/permit.ts` |
| รายงาน PDF (หลายหน้า) / Excel / CSV | `src/utils/pdfGenerator.ts`, `src/utils/exportData.ts` |
| หน้าพิมพ์ (ใช้ภาพหน้า A4 ชุดเดียวกับ PDF) | `src/components/PrintReport.tsx` + `@media print` ใน `src/index.css` |

## หมายเหตุ

- PDF วาดแต่ละหน้าด้วย canvas เพื่อให้เบราว์เซอร์จัดวรรณยุกต์/สระภาษาไทยถูกต้อง จึงเป็นภาพ ไม่สามารถเลือกคัดลอกข้อความได้ ปุ่มพิมพ์ใช้หน้ากระดาษชุดเดียวกับ PDF ผลที่ได้จึงเหมือนกัน (ตั้งค่าเครื่องพิมพ์เป็นขนาดกระดาษ A4 และสัดส่วน 100%)
- ข้อมูลรายการ (ทะเบียน ยี่ห้อ ฯลฯ) อ่านได้โดยทุกคนที่มี URL ของสคริปต์ (และ URL นี้อยู่ในโค้ดของเว็บ) ไม่ควรแชร์ URL ต่อสาธารณะ
- ใช้ TypeScript 6 เพราะ `typescript-eslint` ยังไม่รองรับ TypeScript 7
